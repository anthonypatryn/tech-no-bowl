Game-day sound for Techno Bowl.

- crowd, whistle-start, whistle-final, grunts, effects, themes: the owner's files (see src/data/sounds.json for the cuts).
- steps-a..d: the owner's grass-running recordings (freesound community / evanaeva, Pixabay).
- dice, chip-land-a, deal, fanfare: copied from Long Shot (free Pixabay sound effects, Pixabay Content License, no
  attribution needed): dice roll; poker chip drop 38461 (freesound_community); card dealing; "victory bell success
  fanfare" (emand_edroff).
- coin-flip: "coin flip" 37787 (freesound_community, Pixabay), the owner's pick.
- helmet-smash: "window smash sfx" 382708 (Dragon Studio, Pixabay), the owner's pick for the helmets crashing in the
  opening show.
- Whooshes, menu blips, the dice fallback rattle, the big-hit crack, the sack boom, fire and the kick
  thud are synthesized in code (src/game/sound.js, src/game/useGameSounds.js).
