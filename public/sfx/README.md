Game-day sound for Techno Bowl.

- crowd, whistle-start, whistle-final, grunts, effects, themes: the owner's files (see src/data/sounds.json for the cuts).
- steps-a..d: the owner's grass-running recordings (freesound community / evanaeva, Pixabay).
- dice, coin-flip-a/b, chip-land-a, deal, fanfare: copied from Long Shot (free Pixabay sound effects, Pixabay Content
  License, no attribution needed): dice roll; coin flips 88793 / 37787 and poker chip drop 38461 (freesound_community);
  card dealing; "victory bell success fanfare" (emand_edroff).
- Whooshes, the helmet bash, menu blips, the dice fallback rattle, the big-hit crack, the sack boom, fire and the kick
  thud are synthesized in code (src/game/sound.js, src/game/useGameSounds.js).
