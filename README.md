# tech-no-bowl
Digital recreation of the game Tech No Bowl

8-bit tabletop football from the More Fun! League, in the browser. Players are textured cubes on a 3D field.

- `npm install`, then `npm run dev` (port 5192 via `.claude/launch.json`)
- `?view=art` opens the Art Review Board
- Plan: `docs/PLAN.md`. Notes for Claude: `CLAUDE.md`
- Source print-and-play art is kept locally (gitignored). `npm run art` regenerates `public/art/`
